# Hotel Reservations Cancellation — Big Data Case Study

Case study for the **Big Data** course.

Predicts whether a hotel booking will be cancelled by comparing six classification algorithms.

## Contents

| File | Description |
|------|-------------|
| [Hotel_Reservations_Case_Study.ipynb](Hotel_Reservations_Case_Study.ipynb) | Preprocessing and comparison of KNN, Decision Tree, Naive Bayes, SVM, Logistic Regression and Random Forest (accuracy, precision, recall, F1) |

## Dataset

[Hotel Reservations Dataset](https://www.kaggle.com/datasets/ahsan81/hotel-reservations-classification-dataset) on Kaggle — download `Hotel Reservations.csv` and place it next to the notebook.
